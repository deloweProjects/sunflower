# sunflower.co.zw

- `frontend/index.html`   the home page (welcome, projects)
- `frontend/linc/`        the Linc landing page, served at https://linc.sunflower.co.zw
- `frontend/vercel.json`  sends requests for the linc.* host to `frontend/linc/`

Static, no build step. The previous site (Project Sunflower) is in git history (last commit e7d1548),
and a full copy lives in the owner's BACKUP folder.
